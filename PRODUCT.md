# Product

## Purpose

MatplotLibAPI provides reusable, local-first Python tools for building clear,
consistent data visualizations from pandas data.

## Mission

Make production-quality plotting simple, typed, predictable, and equally safe
for developers and AI agents.

## Product promise

Every supported interface should be:

- easy to discover
- explicit and schema-driven
- deterministic and locally executable
- typed and backward compatible
- safe by default
- documented, tested, and production ready

## Principles

- Developer experience first.
- One canonical contract across interfaces.
- Explicit over magic.
- Simple over clever.
- Reliability over feature count.
- Local and credential-free by default.
- Documentation, tests, types, schemas, and evaluations are part of every feature.

## Guiding question

> Does this make MatplotLibAPI easier and safer to use for both people and agents?
