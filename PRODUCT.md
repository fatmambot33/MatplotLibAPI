# Product

## Purpose

MatplotLibAPI provides reusable Python tools for building clear, consistent data visualizations.

## Mission

Make production-quality plotting simple, typed, and predictable.

## Principles

- Developer experience first.
- Explicit over magic.
- Simple over clever.
- Reliability over features.
- Documentation, tests, and types are part of every feature.

## Guiding Question

> Does this make MatplotLibAPI easier and safer to use?
