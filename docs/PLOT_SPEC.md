# Plot specification contract

`PlotSpec` is the canonical request format for MatplotLibAPI 4.2. It is designed
to be authored by people, stored as JSON, generated by agents, and executed by
Python, the CLI, MCP, or plugin-aware applications.

## Minimal specification

```json
{
  "schema_version": "1.0",
  "chart": "bar",
  "encoding": {
    "category": "product",
    "value": "revenue"
  },
  "options": {
    "stacked": true
  },
  "output": {
    "format": "png",
    "path": "charts/revenue.png",
    "dpi": 150,
    "transparent": false
  }
}
```

## Fields

- `schema_version` identifies the portable contract. Version `1` migrates to
  `1.0`; unsupported versions fail explicitly.
- `chart` is a canonical plot name or registered alias.
- `encoding` maps semantic chart roles to DataFrame columns.
- `options` contains non-encoding plotting options.
- `title` is included only when provided.
- `data` optionally contains either `csv_path` or inline `table` records.
- `output` selects `figure`, `png`, `svg`, or `json`, plus an optional path.
- `metadata` carries caller-owned JSON metadata and is not passed to renderers.

A parameter cannot occur in both `encoding` and `options`. The legacy `params`
object migrates to `options` when no modern parameter objects are present.

## Validation

`PlotValidationError` contains one or more `ValidationIssue` objects. Each issue
has a stable code, message, field path, severity, and optional details.
Representative codes include:

- `spec.missing_chart`
- `spec.unsupported_version`
- `plot.unknown_chart`
- `parameters.missing_required`
- `parameters.unknown`
- `data.missing_column`
- `policy.output_outside_workspace`
- `policy.max_cells_exceeded`
- `output.format_not_supported_by_plot`

## Local safety policy

`RenderPolicy` constrains execution to a workspace and enforces maximum rows,
columns, cells, input bytes, and output bytes. Relative input and output paths
must remain inside the workspace. Absolute paths are disabled by default.

Embedding applications may explicitly construct a different policy, but CLI and
agent integrations should use the restrictive defaults.

## Discovery

```python
from MatplotLibAPI import PlotSpec, create_registry

schema = PlotSpec.json_schema()
registry = create_registry()
descriptor = registry.context.describe_plot("bar")
tools = registry.context.openai_tools()
```

The JSON Schema, registry descriptors, CLI discovery output, MCP metadata, and
OpenAI function tools all derive from the same contracts.
